隱私權政策(Privacy Policy)

最後更新:2026-10-10

「iwei0222 一鍵同發」是僅供本人自用的發文工具,沒有其他使用者。它把我自己製作的短影音與貼文,一次發佈到我自己管理的 Instagram、Facebook 粉絲專頁、Threads、TikTok 與 YouTube 頻道。

1. 蒐集的資料

  • 僅有我本人授權各平台時取得的存取權杖(access token / refresh token),用來代我本人發佈內容。
  • 不蒐集、不儲存、不分享、不販售任何第三方使用者的個人資料,也不讀取、修改或刪除我頻道上既有的影片、留言或設定。
  • 工具只會把我提供的影片檔、標題與說明文字,傳送到我自己的帳號。

2. 儲存方式

  • 權杖只儲存在我本人電腦的本機設定檔,不上傳到任何伺服器,也不與他人分享。
  • 工具不保存各平台 API 回傳的資料,只在畫面上顯示發佈結果(例如影片編號與網址)。

3. YouTube API 服務(YouTube API Services)

本工具使用 YouTube API 服務(YouTube Data API v3 的 videos.insert,權限範圍為 youtube.upload)上傳 YouTube Shorts 到我自己的頻道。使用本工具即表示受 YouTube 服務條款約束。Google 對資料的處理方式,請見 Google 隱私權政策。

4. 撤銷存取與資料刪除

  • 可隨時在 Google 帳戶的第三方存取權頁面撤銷本工具對 YouTube / Google 帳戶的存取權;其他平台也可在各自的「已授權應用程式」設定中撤銷。
  • 撤銷後,本機設定檔裡對應的權杖即失效;我也會刪除本機設定檔中的權杖。
  • 因本工具不保存任何使用者資料,沒有其他資料需要刪除。如有疑問請來信 dj94ru4@gmail.com。

5. 資料用途

僅用於發佈本人製作的內容,不用於廣告、分析、側寫或販售。

dj94ru4@gmail.com

Privacy Policy (English)

"iwei0222 一鍵同發" is a personal-use publishing tool with no other users. It publishes my own videos and posts to my own Instagram, Facebook Page, Threads, TikTok and YouTube accounts.

Data handled. The only data the tool handles are the access/refresh tokens that I (the owner) grant to my own accounts. It does not collect, store, share or sell personal data of any third party, and it does not read, modify or delete my existing channel content. It only sends the video, title and description that I provide to my own accounts.

Storage. Tokens are stored only in a local settings file on my own computer. They are never uploaded to a server and never shared. The tool does not retain API response data; it only shows the result (for example a video ID) on screen.

YouTube API Services. This tool uses YouTube API Services (YouTube Data API v3, method videos.insert, scope youtube.upload) to upload YouTube Shorts to my own channel. By using the tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access and deletion. Access can be revoked at any time at https://myaccount.google.com/permissions (and in each other platform's authorized-apps settings). After revocation the stored tokens stop working and I delete them from the local settings file. Because the tool stores no user data, there is nothing else to delete. Questions: dj94ru4@gmail.com.

Purpose. Publishing my own content only; no advertising, analytics, profiling or resale.
